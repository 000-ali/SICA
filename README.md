# SiCA - Sistema de Compartilhamento de Arquivos

## Descrição

Projeto desenvolvido em Java para realizar o compartilhamento de arquivos entre um cliente e um servidor utilizando sockets TCP.

## Funcionalidades

- Enviar arquivos do cliente para o servidor.
- Listar os arquivos disponíveis no servidor.
- Baixar arquivos do servidor para o cliente.

## Tecnologias

- Java
- Sockets TCP
- Git e GitHub

## Estrutura

- src: códigos Java do cliente e servidor.
- arquivos_servidor: arquivos armazenados no servidor.
- downloads: arquivos baixados pelo cliente.
